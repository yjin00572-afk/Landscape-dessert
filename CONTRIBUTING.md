# Contributing

Useful contributions include stronger visual-to-edible mappings, better failure-mode rules, new source-image categories, improved multilingual prompts, better fine-dining plating guidance, reproducible examples, and clearer runtime integration documentation.

## Contribution Principles

1. Source-image fidelity comes before generic beauty.
2. Dessert elements should be plausibly edible.
3. Results should remain contemporary and premium.
4. Avoid turning the skill into a generic cake generator.
5. New rules should improve consistency across different source images.

## Pull Requests

Explain what problem the change addresses, what behavior changes, and include a before/after example when relevant.

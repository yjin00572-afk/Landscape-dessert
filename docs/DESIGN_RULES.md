# Design Rules

## 1. Preserve Visual Identity

Every output should preserve at least one color relationship, one structural relationship, and one signature subject/detail relationship.

## 2. Translate Materials

- glass → isomalt / jelly
- water → glaze / gel
- stone → sablé / crumble
- petals → chocolate / sugar / wafer paper
- architecture → chocolate frames / geometric mousse
- mist → mousse / foam / granité

## 3. Avoid Generic Cake Language

Avoid round frosted cake defaults, piped cream borders, birthday decorations, random macarons, oversized gold leaf, and flowers unrelated to the source.

## 4. Use Focal Hierarchy

Use one hero element, one supporting material family, and one restrained accent family.

## 5. Keep Edibility Legible

If a component looks like glass, metal, stone, fabric, paper, or plastic, explicitly identify its edible medium.

## 6. Match Mood

A dark source should not automatically become a bright pastel dessert. A quiet source should not become visually noisy. A geometric source should preserve structure. A botanical source should preserve organic rhythm.

## 7. Photography Should Support, Not Overpower

Lighting and background should reinforce the dessert concept without becoming the main subject.

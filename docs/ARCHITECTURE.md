# Architecture

## Pipeline

```text
Uploaded image
      ↓
Source selection
      ↓
Visual DNA analysis
      ↓
Hero-feature selection
      ↓
Visual → edible material translation
      ↓
Dessert format selection
      ↓
Composition + plating design
      ↓
Image prompt construction
      ↓
Image generation
      ↓
Quality gate
```

## Design Layers

1. **Perception** — identify what makes the source image visually unique.
2. **Translation** — map source materials and structures to believable pastry materials.
3. **Pastry Architecture** — convert translated elements into one coherent dessert.
4. **Art Direction** — apply a consistent luxury-food-photography language.
5. **Quality Control** — suppress generic cakes, clutter, non-edible materials, and source drift.

Consistency should come from a repeatable transformation pipeline, not a single magic prompt.

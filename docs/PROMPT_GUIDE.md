# Prompt Guide

## Formula

```text
Source identity
+ visual DNA
+ hero elements
+ dessert format
+ edible material mapping
+ composition
+ plating
+ photography
+ negative constraints
```

## Weak Prompt

```text
Turn this picture into a beautiful cake.
```

## Strong Prompt Pattern

```text
Transform the uploaded source image into a high-end contemporary plated dessert.
Preserve the pale-blue floral clustering, soft ivory centers, layered botanical rhythm,
and fresh green accents. Translate the flowers into delicate white-chocolate and sugar
petals, the soft color field into a pale-blue mousse, and the dew-like highlights into
small clear gel droplets. Build an asymmetrical floral composition with restrained
negative space on a fine porcelain plate. Use realistic edible materials, elegant
fine-dining plating, soft editorial food photography, and natural micro-texture.
Avoid generic birthday-cake styling, excessive decoration, and plastic-looking flowers.
```

## Debugging

If output is generic, add source-specific geometry, color relationships, and explicit edible material mappings.

If output is too decorative, add restrained, controlled garnish, negative space, one focal point, and minimal secondary accents.

If output looks fake, add realistic pastry materials, believable chocolate thickness, tempered chocolate, thin tuile, food-safe sugar work, realistic mousse texture, and natural plate shadows.

If output drifts from the source, repeat the 2–3 most identifiable traits plus one structural and one material correspondence.

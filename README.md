# Isolated Soviet Block Collage

一个为 Codex 设计的图像处理 skill，用来把用户上传的原图转换成“外区完全保真、内区局部苏联线稿重绘”的严格隔离拼贴效果。

它的核心目标不是把整张图做成统一风格化海报，而是只在若干个不规则内部块中进行重绘，同时保证块外区域 100% 保持原图内容不变。

## 功能概述

这个 skill 适用于以下任务：

- 基于用户原图生成“局部拼贴 + 局部苏联海报线稿”的高约束编辑提示词
- 先输出方案，再继续调用图像编辑或生成工具完成图片
- 只在内部块中进行风格化，避免整图被错误重绘
- 让块体具有贴纸、纸片、浮雕、分块地图或立体拼贴的层次感
- 保持输出宽高比与原图完全一致

## 核心约束

这是一个强约束 skill，以下规则默认不可破坏：

- 块外区域必须保留原图，不能重绘、变色、滤镜化、模糊化或重新解释
- 只有内部块允许生成新的苏联线稿内容
- 内部块颜色必须来自原图，不允许套用固定模板色盘
- 内部块中的内容必须是对被遮挡原图区域的重绘，而不是随机生成的新图
- 所有线稿、文字、纹理和装饰必须严格限制在块内
- 默认禁止红色圆章、红色圆徽、红色圆盘等圆形红色符号，除非用户明确要求
- 最终输出比例必须与原图一致

任何把整张图一起风格化、让线稿溢出块外、改动块外原图、或者使用脱离原图的配色方案的结果，都应视为失败。

## 默认工作流

这个 skill 内置“先给方案，再生成”的默认协议。

默认执行顺序如下：

1. 读取原图和参考图
2. 输出一版简明方案
3. 给出最终 `prompt` 和 `negative prompt`
4. 如果图像生成或编辑工具可用，则继续在同一任务内生成结果
5. 如果第一轮结果违反外区保真、块内隔离、源色限制或比例限制，则收紧提示词后再重试一次

只有在用户明确要求“先确认”“先看方案”或“先别生成”时，流程才会停在方案阶段。

## 输出内容

正常情况下，这个 skill 会先产出以下内容：

- 原图诊断
- 提取出的主色与冷暖倾向
- 内部块布局方案
- 每个块内部的重绘计划
- 最终编辑 `prompt`
- `negative prompt`
- 简短验收清单

如果图像工具可用，并且用户没有要求暂停，它会继续生成图片结果。

## 使用方式

### 1. 直接调用

```text
Use $isolated-soviet-block-collage on this image.
```

### 2. 先给方案，再生成

```text
Use $isolated-soviet-block-collage 先给方案，再生成。
```

### 3. 只要提示词，不要生成

```text
Use $isolated-soviet-block-collage 给我最终 prompt，不要直接生成。
```

### 4. 直接应用到图片

```text
Use $isolated-soviet-block-collage 直接应用到这张图。
```

## 适合的图像类型

这个 skill 更适合以下类型的输入图：

- 主体清晰、局部结构明确的人像、街景、建筑、静物或场景照
- 画面中心或偏中心区域适合放置 2-5 个内部块
- 原图本身具有可提取的主色结构，适合转译为块内底色
- 需要保留原图叙事，同时增加局部图形化冲击力的内容

如果原图信息过于混乱、主体极弱、或者参考图要求与“块外保真”相冲突，结果通常会更难稳定。

## 常见失败情况

如果结果出现以下问题，通常说明提示词需要进一步收紧：

- 整张图都被风格化了
- 块外区域被重绘或被改色了
- 线稿溢出到块外
- 内部块颜色与原图无关
- 内部块像平面贴纸，没有厚度或阴影
- 块内内容不是对原图遮挡区域的重绘，而是随机新图
- 输出比例被改掉了

## 与图像工具配合的建议

这个 skill 最适合和图像编辑工具一起使用：

- 先由 skill 产出高约束提示词
- 再将提示词交给图像编辑或图像生成工具执行
- 如果首轮结果失败，优先减少块数量、增强“块外锁定”措辞，并重复强调“块内重绘基于遮挡区域”

如果你只想拿提示词，它也可以只停留在方案输出阶段。
